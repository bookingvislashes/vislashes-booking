# Service photos

Each service on the booking page can carry a photo. Drop the file here, then
paste its path into **Admin → Services → (the service) → Photo**, for example:

    /images/services/classic-set.jpg

The filenames below are only a suggestion — the path in Settings is what
matters, so anything here works as long as the two agree.

    classic-set.jpg     Classic Set
    wispy-set.jpg       Wispy Set
    hybrid-set.jpg      Hybrid Set
    lash-lift.jpg       Lash Lift

The cards render at roughly 340x96 and crop to fill, so a landscape crop
centred on the eyes reads best. A full https:// URL works too, for a photo
hosted somewhere else.

Leave the field blank and the card shows a plain tan block rather than a
broken image.
